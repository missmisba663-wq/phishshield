About PhishShield v{{ version }}

An AI-powered, multi-channel phishing detection and awareness platform built in Python with scikit-learn, OpenCV and Flask, trained on public Kaggle datasets.

System architecture

  ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌───────────────────┐
  │ SMS / chat   │   │ Email / .eml │   │     URL      │   │  QR image/camera  │
  └──────┬───────┘   └──────┬───────┘   └──────┬───────┘   └─────────┬─────────┘
         │                  │ header parser    │                     │ OpenCV decode
         │                  │ (SPF/DKIM, spoof)│                     │ payload type
         ▼                  ▼                  ▼                     ▼ (URL / UPI / Wi-Fi)
  ┌─────────────────────────────────────────────────────────────────────────────┐
  │ Feature extraction: TF-IDF words + char n-grams, 22 lexical URL features    │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │ ML models (best of LogReg / LinearSVC / SGD / NB per channel)               │
  │ + Rule engine (urgency, threats, credential requests, brand abuse …)        │
  │ + Embedded-link analysis (URLs inside SMS/email go through the URL model)   │
  ├─────────────────────────────────────────────────────────────────────────────┤
  │ Risk score 0-100 = 0.8 × ML probability + red-flag points  → safe/suspicious/phishing │
  │ Explainability: per-token contribution (tf-idf × model weight)              │
  └──────────────────────────────┬──────────────────────────────────────────────┘
                                 ▼
        Flask web UI  ·  REST API /api/v1  ·  SQLite history  ·  Awareness quiz

curl -X POST http://127.0.0.1:5000/api/v1/scan/url \
     -H "Content-Type: application/json" \
     -d '{"url": "http://paypa1-login.xyz/verify"}'

Limitations & future work

  • URL analysis is lexical only (no live page fetch / WHOIS) for safety and speed; a sandboxed page-content model could be added.
  • The SMS dataset is general spam; dedicated smishing datasets in Indian languages would improve regional coverage.
  • Transformer models (DistilBERT) may improve accuracy at higher compute cost; linear models were chosen for speed and explainability.
  • Browser extension and email-client add-in would bring real-time protection to where users actually click.
